## Boot to Preloader mode

### Using VOL- button + Power button & USB connection

* Power off the phone
* Connect the phone to the PC
* Hold **VOL-** and **Power** buttons
* The phone should appear briefly as a MediaTek Preloader USB device

## Phone management in Preloader mode

You can use tools such as `mtkclient` to communicate with the device through the Preloader mode. (See [Tools](../dev/tools.md))
